Networking Concepts

This page explains the networking concepts used by my public website, including DNS resolution, IP addressing, HTTPS, status codes, request headers, and response headers.

DNS and IP Addressing

When a user visits ngocbnguyen.github.io, DNS resolves the domain name into GitHub Pages IP addresses. The site uses IPv4 addresses such as 185.199.108.153, 185.199.109.153, 185.199.110.153, and 185.199.111.153.

HTTPS and Status Codes

My website uses HTTPS, which encrypts communication between the browser and the GitHub Pages server. When the page loads successfully, the server returns the status code 200 OK.

Request and Response Headers

Request headers are sent by the browser and include information such as the host, user agent, and accepted file types. Response headers are sent by the server and include information such as content type, caching rules, and security settings.

Performance Optimization

This site uses Bootstrap through a CDN. A CDN helps improve loading speed by serving files from distributed servers. The site also keeps files lightweight to reduce unnecessary network traffic.

Monitoring and Analysis

Google Analytics is used to monitor website traffic, active users, page views, and visitor behavior. Browser Developer Tools are also used to inspect HTTPS requests, status codes, and headers.
